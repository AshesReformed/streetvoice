# Putting StreetVoice online

StreetVoice runs as one free Render web service and talks to Supabase, Gemini and (optionally) an Android SMS phone. All of this is free. The only thing that costs money is the SIM's SMS bundle.

## 1. Create the Render service

1. Sign in at [render.com](https://render.com) with GitHub.
2. Click **New → Blueprint** and pick the `streetvoice` repository. Render reads `render.yaml`.
3. Fill in the values it asks for:

| Setting | Where to get it |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → API (same as your `.env.local`) |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Same page, the anon / public key |
| `SUPABASE_SERVICE_ROLE_KEY` | Same page, the **service_role** secret key |
| `GEMINI_API_KEY` | [aistudio.google.com](https://aistudio.google.com) → Get API key |
| `PUBLIC_BASE_URL` | Your Render address, e.g. `https://streetvoice.onrender.com` (set it after the first deploy, then redeploy) |
| `SMS_GATEWAY_*` | Leave empty until the SMS phone is set up ([SMS-PHONE.md](SMS-PHONE.md)) |

`WEBHOOK_SECRET` is generated by Render. Copy it from the service's Environment tab if you need it for the retry job below.

4. Click **Apply**. The first build takes a few minutes. Then open `https://<your-app>.onrender.com/api/health`, which should say `healthy`.

## 2. Keep it warm before a demo

The free plan sleeps after about 15 minutes without traffic, and the first request after that takes about a minute. Open the site a few minutes before presenting.

## 3. Retry job (recommended)

If the AI is busy (the free tier sometimes is), a complaint waits in "Processing". A free scheduler can retry those every 5 minutes:

1. Sign up at [cron-job.org](https://cron-job.org) (free).
2. Create a job:
   - URL: `https://<your-app>.onrender.com/api/jobs/process-pending`
   - Method: `POST`
   - Header: `x-webhook-secret: <WEBHOOK_SECRET>`
   - Schedule: every 5 minutes

This also keeps the free service awake.

## 4. Demo accounts

Run `npm run seed:officers` locally (it uses `.env.local`). The control-room login is `admin@streetvoice.pk` with the password from `SEED_ADMIN_PASSWORD`. Run `npm run seed:demo` to fill the dashboards with about 50 sample complaints, and `npm run seed:demo -- --clear` to remove them.

## 5. Switching things off

- `SIMULATOR_ENABLED=false` turns off the public `/call` page.
- `SMS_PROVIDER=mock` logs SMS on the SMS page instead of sending them.
